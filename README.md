# .WALLET
Manage multiple **blockchains** with **[.me](https://github.com/neurons-me/.me)**, making it easy to organize and *manage your crypto* assets. 

- Export keys → you are now fully sovereign. Loss = unrecoverable.
- Deterministic, user-triggered payments
- You don’t manage money—you trigger actions that have a cost. and a gain.

This project uses dot-prefixed directories as system-level modules:
- `.me` → identity layer  
- `.wallet` → economy layer  
These may be hidden by default in your editor or OS.
